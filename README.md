# Task-4-SQL-Data-Analysis

## Project Overview

This project demonstrates SQL data analysis using an E-commerce Management System database. The database contains customer, product, order, and order details data.

## Tools Used

* MySQL
* MySQL Workbench
* GitHub

## Database Tables

The project contains the following tables:

1. Customers
2. Products
3. Orders
4. OrderDetails

## SQL Concepts Covered

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* HAVING
* Aggregate Functions: SUM() and AVG()
* INNER JOIN
* LEFT JOIN
* RIGHT JOIN
* Subqueries
* Views
* Indexes
* NULL Handling using COALESCE()

## Key Analysis Performed

* Calculated total revenue.
* Calculated average order value.
* Identified best-selling products.
* Analyzed customer order details and total spending.
* Performed different types of SQL joins.
* Used subqueries to analyze products and customer spending.
* Created a view for customer order summaries.
* Created an index to demonstrate query optimization.
* Demonstrated NULL value handling.

## Project Files

* `E-commerce Management System.sql` – Database tables and sample data.
* `task4_sql_queries.sql` – SQL queries used for analysis.
* `screenshots of output/` – Screenshots of SQL query outputs.

## Outcome

This project helped me practice querying and analyzing structured data using SQL and MySQL Workbench.
